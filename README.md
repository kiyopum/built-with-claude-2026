# YaoBiz（ヤオビズ）

> **AI が生み出すのは、仕事を奪われる未来ではない。**
> **今まで仕事にできなかった力が、仕事になる未来だ。**

眠っている商いを、空いた時間で掘り起こして売る。

売るものはあるのに、ネットでの売り方がわからない地域の小さな事業者。時間に縛られずに働きたいパートナー（主に主婦の方）。YaoBiz はこの2つをつなぎ、**ヒアリング → 法律チェックと修正 → 公開・販売 → 成果の記録**までを、パートナーのスマホ1台で進められるようにします。

- ハッカソン「Built with Claude: Japan 2026」の作品です。**ハッカソン期間中（2026-11-03〜）にゼロから実装しました**（既存のアプリのコードは持ち込んでいません）。
- 作ったのは 株式会社山崎メディアミックス です。
- 画面に出てくる事業者名・人名・商品・金額は、すべて架空のダミーです。

## なぜ作ったか

AI で何でもできるようになった今、効率だけを求めると人が置き去りになります。けれど、誰もが働かずに食べていける世界になるまでは、人には仕事と、その対価が要ります。

YaoBiz は「AI が人の仕事を減らす」ではなく、**「AI が人に仕事を生む」**ための道具です。事業者さんに足を運んで話を聞くのも、公開のボタンを押すのも人。Claude は裏方として、聞き漏らしを防ぎ、文章を起こし、法律を調べ、確かめます。

## 流れ（3ステップ）

1. **ヒアリング**（パートナー）
   - 事業者の業種とホームページから、Claude が「聞くことリスト」を作ります。ホームページに載っていないことだけを聞きます。
   - 録音ボタンで話を聞き、そのまま文字になります（打ち間違いは手で直せます）。名刺の写真から、事業者の情報を読み取ります。
   - 商品の写真（ラベルも）を撮ると、Claude が写真と話から商品ページの下書きを作ります。
2. **法律チェックと修正**
   - 事業者ごとに、Claude が国の公式サイト（消費者庁・厚生労働省・農林水産省・e-Gov など）だけを検索して、売るときの法律を調べます。出典の URL を残します。
   - 商品ページと SNS の投稿は、その調査をもとに、食品表示・景品表示法（言いすぎ）・ステマ規制（#PR）の面から確かめます。
   - 事業者さんの一言で Claude が直します（AI での作り直しは5回まで。手でも直せます）。
3. **公開（リリース）**
   - **公開のボタンを押せるのは事業者さんだけ**です。事業者さんはログインせず、パートナーのスマホで事業者さんの暗証番号4けたを入れて押します。
   - 商品ページ・QR・紹介の投稿（画像4枚と本文）ができ、Stripe Checkout（テストモード）で買えます。
   - 値段は「1個の値段」を入れ、事業者さんが「1箱に入れる数」を決めると、お客さまには「20個入り 送料込み 3,600円」のようなひとつの値段で出ます（「○円＋送料」とは出しません）。
   - 売れたら、事業者さん・担当パートナー・運営にアプリとメールで知らせます。事業者さんは、メールのリンクと自分の暗証番号だけで開ける専用ページで、注文と届け先を見られます（アカウントは要りません）。
   - 注文ごとに「事業者／パートナー／YMM」の取り分が明細に並びます。

## お金は「責任」に払う

| 種類 | 分け方 |
|---|---|
| 物販 | 売上の1割が YMM の取り分。そこから売上の3.6%にあたる決済手数料を払い、残り（売上の6.4%）をパートナーと YMM で半分ずつ（各3.2%）。事業者は9割 |
| サービス（ライブ配信・講座・体験） | 講師5割。残りから決済手数料を払い、パートナーと YMM で半分ずつ（各23.2%） |
| 商品ごとの決め方 | 運営が商品ごとに割合を変えられます（5〜70%）。割合でなく「1個あたりの営業費用（固定額）」をパートナーに渡す決め方もできます |
| 紹介 | ほかのパートナーの商品を紹介して売れたら、パートナーの取り分を担当と紹介者で半分ずつ |

- **送料には1割をかけません**（運ぶ責任は YMM にもパートナーにもないため）。大きさと重さから大手（日本郵便・ヤマト）のいちばん安い送り方を選び、届け先の都道府県で「送料込み ○円」を出します。料金は各社の公式サイトの表だけを使っています。
- パートナーが自分の車で届けてお金を受け取ることはしません（無許可の有償運送になるため）。
- 契約の条件（業務の内容・報酬の計算・支払期日）を明細の画面に出しています（フリーランス新法の明示義務）。
- **分配の送金はアプリの外**で行います。本番では Stripe Connect（マーケットプレイス型）で自動で送金する設計です。購入代金は Stripe Checkout で動きます。

## 人を置き去りにしないための手立て

- **人がしたこと／AI がしたこと**：商品ページに、記録が残っていることだけを並べます。「出すかどうかを決めたのは、事業者の方です」。
- **ありがとうの往復便**：箱に入れるカードの QR から、お客さまが事業者さんに一言。事業者さんが暗証番号でお返事します。
- **みんなの声**：お褒めも要望も、スタッフみんなで分け合います。きびしい言葉は Claude が責めない形に整え、名前や連絡先は消します。
- **事業者の言葉の本**：後を継ぐ人へ。事業者さんの言葉は、ヒアリングの文と一字一句同じものだけを載せます（プログラムで照らし合わせます）。
- **売れなくても責めない伴走**：注文のない商品に、Claude が次の小さな一歩を1つだけ提案します。「売れていない」とは書かず、値下げもすすめません。近い行事（お歳暮・帰省の手みやげなど）に自然に合えば添えます。
- **月1のふり返り・わたしの歩み・今月のお休み**：順位や売上ではなく、してきたことの数と「できるようになったこと」を残します。休むのに理由は聞きません。

## Claude の使い方

アプリの中の Claude（`claude-opus-5-5`、`lib/claude.ts`）は、**型を決めた出力**（zod の構造化出力）で返させ、画面とデータベースにそのまま流します。

| 場面 | 使っている機能 |
|---|---|
| ホームページを探す・読む | `web_search` で候補を出し人が選ぶ。`web_fetch` は**その事業者のドメインだけ**・最大4ページ |
| 法律の調査 | `web_search` を**国の公式サイトのドメインだけ**に絞る。出典は実際に検索で出たページだけを残す |
| 写真・名刺・ラベル | 画像の読み取り（原材料名・アレルギーなどの表示の確認） |
| 商品ページ・投稿 | 下書き、作り直し、公開前の法律チェック（投稿は別にもう一度） |
| 声・ふり返り・本・歩み | 言葉を整える、気持ちを読む（診断はしない）、原文だけで本にする、記録の数字だけでまとめる |

API の料金（売れても売れなくてもかかる＝YMM の持分）を抑える工夫も入れています。

- **法律の調査は日数で区切らず**、調査の最後に書かせた「施行予定: YYYY-MM-DD」の日が来たら調べ直します（法律は国のサイトに施行日が書いてあり、急には変わらないため）。
- **同じ材料なら同じ法律**：売る物の種類が同じ（またはその一部）の事業者の調査を使い回します。迷うとき、お酒・生ものが絡むときは使い回しません。
- **事前調査**：訪問の予定が決まっている事業者は、事務局が手元の **Claude Code** で先に調べ（`docs/事務局_事前調査.md`）、結果を取り込みます。当日はアプリから API を呼びません。
- 作り直しは5回まで。

このアプリ自体も、Claude Code で作りました。

## 技術

- Next.js 16（App Router）・TypeScript・Tailwind CSS
- SQLite（`node:sqlite`）
- Anthropic TypeScript SDK（`@anthropic-ai/sdk`）
- Stripe Checkout（テストモードだけ）
- 音声入力：ブラウザの音声認識（Web Speech API）。録音ファイルも同時に残します
- 紹介の投稿の画像：ブラウザの canvas で作ります（`components/carousel.ts`）

## 動かし方

```bash
npm install
cp .env.example .env   # 値を書く（下の表）
npm run dev            # http://localhost:3000
```

| 設定（`.env`） | 要るか | 中身 |
|---|---|---|
| `ANTHROPIC_API_KEY` | 必須 | Claude の API キー |
| `STRIPE_SECRET_KEY`・`STRIPE_WEBHOOK_SECRET` | 購入を試すとき | Stripe の**テストモード**のキー（`sk_test_`／`whsec_`）。本番キー（`sk_live_`）は受け付けません |
| `SMTP_URL`・`MAIL_FROM` | 売れたときのメールを送るとき | 無ければ送らず、画面の知らせだけになります |
| `YAOBIZ_DATA_DIR` | 任意 | SQLite・写真・録音の置き場所（既定 `./data`） |
| `YAOBIZ_SETUP_KEY` | 公開サーバーに置くとき | 最初の管理者を作るリンクの合言葉（`NODE_ENV=production` では必須） |
| `APP_BASE_URL` | 公開サーバーに置くとき | 外から見たアドレス。決済の戻り先と、売れたときのメールのリンクに使います |
| `CLAUDE_DAILY_LIMIT` | 任意 | Claude を1日に呼べる回数の上限（既定 400。費用の守り） |

- 最初の管理者は、画面で本人が作ります（名前と暗証番号4けた）。暗証番号は scrypt で変換して保存します。
- 購入の記録は Stripe の Webhook（`/api/stripe/webhook`）で受けます。手元で試すときは `stripe listen --forward-to localhost:3000/api/stripe/webhook` などで転送します。
- Node.js 22.5 以上（`node:sqlite` を使うため。動作確認は Node 23）。
